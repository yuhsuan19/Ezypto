# Ezypto
An easy EVM crypto wallet demo project.


## Assessment Brief
### Time Limit:
- Please submit your work within 72 hours.

###  Requirement Details:

- Wallet import and creation
- Support for Ethereum (ETH), including address display

### Additional Notes:
- Using the MVVM architecture is a plus
- Implementing signing and sending functionality is a plus
- Including unit tests is a plus
- High-fidelity UI is not required for the demo; design assets can be freely sourced online, and pixel-perfect precision is not necessary
